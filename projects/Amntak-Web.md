# Amntak Web — Cybersecurity Learning Platform Client

**Private project — public portfolio documentation**

## Overview

`amntak-web` is the companion web application for the AMAN / Amntak platform. The repository contains the browser-facing experience for authentication, dashboard, courses, hands-on labs, profiles and the platform's social/pulse experience.

## Product Surface

Verified application routes/components include:

- Landing/home experience
- Login and authentication flow
- Dashboard
- Courses
- Hands-on labs
- User profile
- Pulse/social feed
- Protected client routes

The dashboard presents cybersecurity-oriented progression data including points, experience level, rank, active labs, recent-course progress, completed challenges, streaks and achievement status.

## Verified Technology Stack

- Next.js 16
- React 19
- TypeScript 5
- TanStack React Query
- tRPC 11
- Zod 4
- Tailwind CSS 4
- Framer Motion
- Lucide React
- Sonner
- ESLint

## UX & Engineering Characteristics

- App Router structure
- Client-side protected views
- Query-based data fetching and caching
- Typed API interaction through tRPC
- Schema validation with Zod
- Responsive UI components
- Motion and feedback patterns for a security-learning experience

## Architecture Relationship

This repository acts as the web client for the private AMAN / Amntak backend. The backend exposes the core application services and the web client consumes those services for the user-facing product experience.
