# Security Policy

## Scope

This portfolio repository contains public documentation, indexes, and references to selected cybersecurity work.

## Responsible Disclosure

If you identify a security issue in code maintained in this repository or in one of the linked projects, please report it privately before public disclosure whenever possible.

Do not include credentials, private keys, tokens, personal data, or sensitive production information in public issues.

## Authorized Testing

Security testing described in this portfolio is intended only for systems and environments where authorization has been granted.
