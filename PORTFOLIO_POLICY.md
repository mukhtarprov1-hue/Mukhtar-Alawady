# Portfolio Policy

## Purpose

`Mukhtar-Alawady` is a public portfolio and documentation repository. It is intended to organize and present my work without replacing the original repositories that contain the projects themselves.

## Source-code preservation

- Existing project repositories are **not deleted, renamed, moved, or overwritten** by this portfolio.
- Source code is **not copied into this repository** merely for presentation.
- Private project repositories remain private unless I explicitly choose to change their visibility.
- This repository may contain project summaries, documentation, architecture notes, links, screenshots, diagrams, and other non-sensitive portfolio material.

## Security

Do not commit credentials, API keys, tokens, private data, proprietary information, or sensitive production details.

## Project integrity

Each project remains the authoritative source for its own implementation. This portfolio acts as an index and presentation layer.
